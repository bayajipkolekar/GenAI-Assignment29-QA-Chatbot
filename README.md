
# Assignment 29: Q&A Chatbot Application (OpenAI & Ollama)

## Objective
Build a conversational Q&A chatbot using OpenAI cloud models and Ollama local models with LangChain.

## Project Tasks
1. Configure the OpenAI API key using environment variables.
2. Build a basic OpenAI Q&A chatbot.
3. Test at least five different questions.
4. Explore multi-turn conversation history.
5. Install Ollama and pull a local model.
6. Build an Ollama chatbot using LangChain.
7. Compare OpenAI and Ollama responses.
8. Create a unified chatbot with model switching.
9. Build a simple command-line or Streamlit interface.
10. Record observations and insights.

## Technologies
- Python
- LangChain
- OpenAI API
- Ollama
- Streamlit (optional)

## Setup
Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Configure your OpenAI API key in the `.env` file. Never upload real API keys or passwords.

## Run
Start the chatbot:

```bash
python main.py
```

## Comparison
Compare OpenAI and Ollama based on response quality, latency, cost, and privacy.

## Conclusion
This project demonstrates how cloud-based and locally hosted language models can power a conversational Q&A chatbot.
